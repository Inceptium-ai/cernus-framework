# Changelog

## 0.1.0 — 2026-08-23

- Initial open core: contracts (`cernus.ai/v0`), canonical model, plugin SDK,
  deterministic policy engine, `cernus` CLI, NIST 800-53 crosswalk catalog.
- Plugins: genesis, trivy (connector + scanner), syft, cyclonedx, sarif (in/out),
  oscal (POA&M + assessment results).
- Packages: `cernus-core`, `cernus-plugins`, `cernus-cli`, and the `cernus`
  meta-package (lockstep versions).
